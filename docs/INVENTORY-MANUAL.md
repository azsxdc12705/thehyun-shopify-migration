# 웹사이트 재고 등록 매뉴얼

thehyun.com 상품·재고를 Shopify 관리자에서 직접 등록하는 방법입니다.
근무자 누구나 이 문서만 보고 할 수 있도록 썼습니다.

---

## 먼저 알아야 할 것 — 한 덩어리 = 한 줄

이 가게의 상품 구조는 일반 쇼핑몰과 다릅니다.

일반 쇼핑몰은 "티셔츠 M 사이즈 12장"처럼 **같은 물건이 여러 개**입니다.
여기는 **진공포장 덩어리 하나하나가 무게도 가격도 다른 별개 상품**입니다.

```
Striploin(채끝)
 ├ 0.40 lb  $56.80   ← 이 덩어리
 ├ 0.45 lb  $63.90   ← 다른 덩어리
 └ 0.53 lb  $75.26   ← 또 다른 덩어리
```

Shopify에서는 이 한 줄 한 줄을 **"변형(Variant)"** 이라고 부릅니다.
그래서 재고 등록은 두 가지 중 하나입니다.

| 상황 | 할 일 |
| --- | --- |
| 전에 없던 무게가 들어왔다 | **변형을 새로 추가** |
| 전에 있던 무게가 또 들어왔다 | **그 줄의 수량만 +1** |

---

## 1. 로그인

1. `admin.shopify.com` 접속
2. 사장님께 받은 계정으로 로그인
3. 왼쪽 메뉴 **Products(제품)** 클릭

계정이 없으면 사장님께 요청하세요. 직원용 계정을 따로 만들 수 있고,
그래야 누가 무엇을 바꿨는지 기록이 남습니다.

---

## 2. 새 덩어리가 들어왔을 때

### 2-1. 상품 찾기

**Products** 목록 상단 검색창에 부위 이름을 영어로 칩니다 (예: `Striploin`).
해당 상품을 클릭합니다.

### 2-2. 무게 줄 추가

화면을 내리면 **Variants(변형)** 목록이 있습니다.

1. 목록 맨 아래 **+ Add variant(변형 추가)** 클릭
2. **Weight** 칸에 무게를 입력합니다 — 형식을 꼭 지키세요:

   ```
   0.53 lb        ← 맞음 (소수점 둘째 자리, 띄어쓰기, 소문자 lb)
   0.53lb         ← 틀림
   0.53 LB        ← 틀림
   0.5 lb         ← 저울이 0.50이면 이렇게 쓰지 말고 0.50 lb
   ```

   형식이 다르면 사이트에 같은 무게가 두 줄로 보입니다.

3. **Price(가격)** 입력 → 아래 4-1 참고
4. **Quantity(수량)** 에 `1` 입력
5. 오른쪽 위 **Save(저장)**

**SKU 칸은 비워두세요.** 핸들과 무게에서 기계적으로 계산되는 값이라, 재고
자동화를 붙일 때 스크립트로 한 번에 넣습니다. 손으로 넣다가 오타가 나면
빈 칸보다 나쁩니다 — 값이 들어가 있어서 스크립트가 고치지 못하고, 나중에
매칭이 조용히 어긋납니다.

### 2-3. 이미 있는 무게가 또 들어왔을 때

변형을 새로 만들지 마세요. 같은 줄이 두 개 생깁니다.

1. 그 무게 줄을 찾습니다
2. **Quantity** 를 `1` → `2` 로 고칩니다
3. **Save**

---

### 2-4. 수량 0인 줄은 지우지 마세요

무게 줄 중에 수량이 `0`인 것들이 있습니다. 전에 그 무게로 팔았던 기록입니다.
**지우지 마세요.**

Shopify는 줄이 하나도 없는 상품을 허용하지 않습니다. 마지막 덩어리가 팔렸다고
줄까지 지우면 무게 옵션 자체가 사라지고, 그 상품은 무게를 못 고르는 상태가
됩니다. 2026년 9월에 사이트 전체가 그렇게 망가졌습니다.

수량 0인 줄은 손님 화면에 안 나옵니다. 관리자에서만 보입니다. 같은 무게가
다시 들어오면 그 줄의 수량만 올리면 되니 오히려 편합니다.

## 3. 팔렸을 때

**수량을 0으로 내립니다. 줄을 삭제하지 마세요.**

삭제하면 과거 주문 기록에서 그 상품이 사라지고, 나중에 같은 무게가
들어왔을 때 처음부터 다시 만들어야 합니다. 0으로 두면 사이트에서는
"sold out"으로 보이고, 다시 들어오면 숫자만 올리면 됩니다.

1. Products → 해당 상품 → 그 무게 줄
2. **Quantity** 를 `0` 으로
3. **Save**

> 매장(Square)에서 팔린 것도 여기서 내려야 합니다. 아직 매장과 웹사이트
> 재고가 자동으로 연결되어 있지 않습니다. 연결되면 이 단계는 없어집니다.

---

## 4. 입력값 규칙

### 4-1. 가격 — 대장에 적힌 값을 그대로

계산하지 마세요. 재고 대장에 무게와 가격이 같이 적혀 있습니다. 그 줄의
가격을 그대로 옮기면 됩니다.

```
대장          Striploin   9/15 입고   0.53 lb   75.26
Shopify       Weight: 0.53 lb         Price: 75.26
```

대장에 가격이 비어 있으면 임의로 계산해 넣지 말고 사장님께 확인하세요.

### 4-2. SKU — 지금은 입력하지 않습니다

`HYUN-STRIPLOIN-053` 같은 코드를 쓸 예정이지만, 부위 이름과 무게에서 그대로
계산되는 값이라 근무자가 입력할 필요가 없습니다. 매장 POS·우버와 재고를
연동할 때 스크립트로 전부 한 번에 부여합니다.

## 5. 하고 나면 반드시 확인

관리자에서 저장했다고 끝이 아닙니다. **실제 사이트에서 눈으로 확인**하세요.

1. `thehyun.com/products/부위영문명` 접속 (예: `thehyun.com/products/striploin`)
2. 방금 넣은 무게가 선택 목록에 나오는지
3. 그 무게를 고르면 가격이 맞게 바뀌는지
4. **Add to Cart** 버튼이 눌리는지

`thehyun.com/available-cuts` 에도 재고 있는 부위만 나옵니다. 여기 안 보이면
수량이 0이거나 가격이 비어 있는 겁니다.

---

## 6. 하면 안 되는 것

**가격을 0 으로 두지 마세요.** 사이트가 "판매하지 않는 상품"으로 보고
품절 처리합니다. 수량이 있어도 안 팔립니다.

**변형 줄을 삭제하지 마세요.** 3번 참고.

**Products → Import(가져오기) 는 쓰지 마세요.** 파일 하나로 전체 카탈로그를
덮어쓰는 기능입니다. 잘못 쓰면 모든 상품의 가격과 무게가 한 번에 지워집니다.
실제로 2026년 9월에 이 일이 일어나 54개 부위 중 53개가 가격 $0이 되고 무게
옵션이 사라져, 사이트 전체가 품절로 표시됐습니다.
가져오기가 필요하면 사장님이나 담당자에게 요청하세요.

**수량 0인 줄을 지우지 마세요.** 2-4번 참고.

**상품 이름(Title)과 주소(Handle)를 바꾸지 마세요.** 주소가 바뀌면 기존 링크와
검색 결과가 전부 깨집니다.

---

## 7. 이상할 때

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 사이트에 sold out으로 나옴 | 수량 0, 또는 가격 0 | 둘 다 확인 |
| 같은 무게가 두 줄 보임 | 무게 표기 형식이 다름 (`0.5 lb` / `0.50 lb`) | 한 줄 수량 0으로, 형식 통일 |
| 저장이 안 됨 | 가격이나 무게 칸이 비어 있음 | 빈 칸 확인 |
| 상품 자체가 안 보임 | 판매 채널에서 빠졌거나 Draft 상태 | 사장님께 문의 |
| 장바구니에 안 담김 | 수량 0이거나 가격 0 | 위와 동일 |

해결 안 되면 **직접 이것저것 눌러보지 말고** 담당자에게 연락하세요.
실제 손님이 보고 있는 사이트입니다.
